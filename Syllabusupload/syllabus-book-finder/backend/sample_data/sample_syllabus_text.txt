Course Title: Advanced Data Structures and Algorithms
Course Code: 21CS42
CIE Marks: 50
SEE Marks: 50
Total Hours: 50
Credits: 04

COURSE OBJECTIVES:
1. Understand the design principles and analysis of complex data structures.
2. Formulate and solve real-world problems using graph algorithms and dynamic programming.
3. Evaluate algorithm complexity using asymptotic notations.

MODULE 1: Linear & Hierarchical Structures
Review of Stacks, Queues, Circular Queues, Priority Queues. Binary Search Trees, AVL Trees, 2-3 Trees, Red-Black Trees, B-Trees and B+ Trees: Operations, Insertion, Deletion, and Amortized Analysis.

MODULE 2: Advanced Graph Algorithms & Flow Networks
Topological sorting, Strongly Connected Components, Minimum Spanning Trees (Prim's and Kruskal's), Single Source Shortest Path (Dijkstra and Bellman-Ford), All-Pairs Shortest Path (Floyd-Warshall), Maximum Flow: Ford-Fulkerson algorithm.

MODULE 3: Disjoint Sets & Dynamic Programming
Disjoint set data structures, Union by rank and path compression. Dynamic programming paradigm: Matrix chain multiplication, Longest common subsequence, 0/1 Knapsack problem, Optimal binary search trees.

MODULE 4: String Matching & Randomized Algorithms
Naive string matching, Rabin-Karp algorithm, Knuth-Morris-Pratt (KMP) algorithm, Boyer-Moore algorithm, Suffix trees. Randomized quicksort, Primality testing.

MODULE 5: NP-Completeness & Approximation Algorithms
Class P, NP, NP-Hard, and NP-Complete problems. Cook's Theorem statement, Reducibility proofs: Vertex Cover, Clique, Subset Sum, Hamiltonian Cycle. Approximation algorithms for Vertex Cover and Traveling Salesperson Problem.

COURSE OUTCOMES:
Upon successful completion of the course, students will be able to:
CO1: Analyze worst-case and amortized running times of complex algorithms.
CO2: Implement advanced trees and graph topologies for high-throughput computing.
CO3: Apply dynamic programming strategies to optimization challenges.
